# Pal — Family Dashboard

This repository contains the separate family-member interface for Pal.

## Open the app
After GitHub Pages is enabled for this repository, open:
`https://serhanjain.github.io/DEMENTIA-FAMILY/`

## Files
- `index.html` — family dashboard
- `icon.svg` — Pal app icon
- `sw.js` — small offline shell cache

## Important current limitations
The dashboard currently shares data with the person's Pal interface only when both are opened in the same browser profile and origin. This separate GitHub Pages site does not yet have a secure cross-device backend or authentication. Location updates and browser notifications also depend on the page being open and browser permissions being granted. This is a prototype, not an emergency monitoring service.
